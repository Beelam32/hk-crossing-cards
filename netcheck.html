網頁連線測試

如果你開過關實況主頁好慢或者開唔到，先開呢頁睇下係邊度出問題。

開始測試⋯
網頁本身（GitHub Pages）待測
數據檔 snapshot.json待測
口岸快拍圖（政府伺服器）待測
後備 CDN（jsDelivr）待測
點睇結果：
• 全部綠 → 網絡冇問題，主頁應該開得到；如果主頁仍然慢，係手機瀏覽器 cache 問題，試下清除。
• 只有快拍圖紅 → 數據睇到，但圖睇唔到。政府圖檔域喺大陸有時唔穩，唔影響文字數據。
• 網頁本身紅 → 你嘅網絡連 GitHub Pages 唔通，可以改用後備連結（問我攞 Cloudflare 網址）。
• 全部紅 → 你而家嘅網絡限制咗境外網站，試下換 WiFi／4G。
